# Тестировщик 1 — Доступ и администрирование

## Инструкция

Адрес: **https://typography.root.sx**. Получите у координатора согласованные
учётные записи, роли, данные и ожидаемые суммы. Пароли сюда не записывайте.
Используйте записи `QA-T1-<название>`; настоящие заказы, общие цены и роли
не изменяйте. Окончательное удаление требует согласования. В среде находятся
исторические бизнес-данные.

Статусы: **Не проверено / Пройдено / Ошибка / Заблокировано**. Проверяйте весь
ожидаемый результат. Без подготовки или эталона ставьте «Заблокировано».
При ошибке укажите URL, время, ввод, ожидаемый/фактический результат и ссылку
на скриншот/задачу. Не публикуйте персональные данные. Ретест допишите с датой,
не стирая первоначальную ошибку.
